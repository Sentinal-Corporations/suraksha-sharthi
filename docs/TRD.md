## 1. Architecture
Flutter (camera/crop/UI/TTS) → Firebase ML Kit OCR (conf) → if <0.70 Gemini 2.5 Flash Vision → drug match NeonDB drug_master → Lite-RAG prompt → Gemini Flash text (Groq/OpenRouter fallback) → save Neon sehat_file + Appwrite storage → Bhashini TTS hi/bn/mr + Flutter_TTS fallback → FCM reminders. See branding/architecture.png.

## 2. Data (real DB wired)
- Master: `mvp/data/medicines.json` — 49 medicines, brand aliases (Dolo/Crocin→paracetamol), mg forms, ICD-11, hi/bn/mr explain + disease names. Mirrors Neon `drug_master`.
- Rules: `mvp/data/interactions.json` — 12 pairwise rules (duplicate, NSAID+BP, Thyroid+Iron...) → Neon `interaction_rules`.
- Seed: `sql/seed_medicines.sql` (generated by `sql/build_seed.py`) — run `psql $NEON_DATABASE_URL -f sql/seed_medicines.sql`.
- App resolves any brand → generic, then checks duplicates + pairs in mother-tongue.
Neon Postgres: drug_master(name PK, mg, disease_en, icd11, hindi, bengali, marathi, red_flag, notes); sehat_file(id uuid, user_phone, scan_type, raw_text, parsed_json jsonb, disease_guess, lang, created_at). Appwrite: bucket parchis (private, 5MB max, jpg/pdf), auth phone-OTP. Local Hive cache last 5 scans.

## 3b. AI engine (pluggable, incl. custom models)
- Default `rules` (offline, MVP): grounded in medicines.json + interactions.json, zero hallucination.
- `gemini`: Vision OCR + grounded explain via server proxy (key in server .env, never frontend).
- `custom`: any OpenAI-compatible model (e.g. self-hosted medical LLM via Ollama/vLLM — set `llm.model`, e.g. "needle-2", + `proxyUrl` in config). Adapter: `mvp/js/llm.js`. Same guardrail prompt as `app/rag_prompt.txt`.

## 3. APIs
- POST /scan: image → {drugs[], conf} ; OCR fallback chain.
- POST /explain: {drugs, labs, lang} → RAG prompt (app/rag_prompt.txt) → {disease_guess, timetable[], voice_script, red_flags[]}.
- POST /tts: {text, lang hi|bn|mr} → Bhashini → mp3; fallback local.
- CRUD /sehat-file: Neon via PostgREST/Prisma; delete cascades storage.
Free quotas: Gemini Flash ~15RPM, Bhashini hackathon free, Neon 3GB, Firebase Spark, Appwrite self-host.
